# User Flows

## 1. 公開地図を見る

1. `/` にアクセス
2. 世界全体の明るい地図が表示される
3. VisitのあるPlaceがクラスタ/ピンで表示される
4. ユーザーはズーム・パンする
5. ズームするとクラスタが分解される
6. 十分ズームするとPlace名が見える
7. Placeピンを選ぶ
8. PCではサイドパネル、スマホではボトムシートを開く
9. 訪問回数・初回/最終訪問・Visit履歴を見る
10. メモを読む、または外部OGPカードを別タブで開く

## 2. 期間で振り返る

1. 期間フィルターを開く
2. 「今年」「去年」等を選ぶ、または開始/終了日を指定
3. 地図が対象Visit集合に切り替わる
4. Place表示、Visit回数、クラスタ数も対象期間で再計算される
5. フィルター解除で全期間へ戻る

## 3. 自分のPlaceを検索する

1. 検索欄にキーワード入力
2. 自分のPlace結果を表示
3. Place名だけでなくVisitタイトル/メモにもマッチ可能
4. 結果選択
5. 地図が該当Placeへズーム
6. Place詳細パネルを開く

## 4. 新しいPlaceにVisitを追加する

管理者のみ。

1. 公開地図上で検索
2. 外部施設検索結果から施設を選択
3. 未登録施設であることを判定
4. Visitフォームを同じサイドパネル/ボトムシート内に表示
5. 訪問日を入力
6. 任意タイトル
7. Markdownメモ
8. 外部リンクを0件以上追加
9. 「メモ or 外部リンク」があることを検証
10. 保存
11. トランザクション内で必要ならPlace作成
12. Visit作成
13. 地図へ反映
14. Place詳細へ戻る

## 5. 再訪を追加する

管理者のみ。

入口は2つ。

### A. Place詳細から
1. Placeピン選択
2. 詳細パネル
3. 「訪問を追加」
4. Visitフォーム
5. 保存

### B. 検索から
1. 検索
2. 既存Place結果を選ぶ
3. 「詳細を見る / 訪問を追加」の導線
4. 訪問追加

同一日Visitがすでに存在する場合は新規作成せず、既存Visit編集へ誘導する。

## 6. Visitを編集する

管理者のみ。

1. Place詳細
2. 対象Visitの編集
3. 同パネル内でフォームに切り替え
4. 日付・タイトル・メモ・外部リンクを変更
5. バリデーション
6. 保存
7. Place詳細へ戻る

## 7. Visitを削除する

管理者のみ。

1. Visit編集またはアクションメニューから削除
2. 確認ダイアログ
3. 最後のVisitの場合はPlaceが地図から消えることを追加表示
4. 削除
5. PlaceにVisitが残っていればPlace詳細更新
6. 0件ならパネルを閉じて地図からPlaceを消す

## 8. URLからPlaceを開く

1. `/?place=<id>` へアクセス
2. 初期地図ロード
3. Placeを取得
4. 該当地点へ移動・ズーム
5. Place詳細を開く

## 9. URLからVisitを開く

1. `/?place=<id>&visit=<id>` へアクセス
2. Place詳細を開く
3. 該当Visitが見えるように展開またはスクロール
4. 必要なら視覚的に一時強調

## 10. 管理者ログイン

1. 一般UIにはログインボタンを出さない
2. `/admin` を直接開く
3. Googleログイン
4. 許可されたGoogleアカウントか確認
5. 成功後は通常の `/` を使う
6. ログイン状態では地図UIに追加・編集・削除操作が見える

## 11. プロフィール編集

1. `/admin`
2. 名前編集
3. 自己紹介編集
4. 外部リンク編集
5. Googleプロフィール画像は読み取りのみ
6. 保存
