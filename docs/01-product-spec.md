# Product Specification

## 基本仕様

公開URL `/` はそのまま地図。

誰でも閲覧可能。

管理者だけ Google ログイン後に Place/Visit の追加・編集・削除、およびプロフィール編集ができる。

一般閲覧者にはログインボタンや管理者向けUIを見せない。

## ホーム

- 初期表示は世界全体
- MVP は平面世界地図
- 地図は明るくミニマル
- Place が地図上にピンとして表示される
- ズームアウト時はクラスタリング
- クラスタの数字は Place 数
- 個別Placeピンは Visit 回数に応じて見た目の強さ（例: サイズ）を変える
- 十分ズームしたときは Place 名を表示
- Placeカテゴリによるピンの差別化はしない

## 期間フィルター

期間による絞り込みを持つ。

- 自由な開始日 / 終了日
- プリセット
  - 今年
  - 去年
  - 過去5年など

期間フィルターは地図上の集計全体に適用する。

例:
- 2026年にVisitしたPlaceだけ表示
- PlaceピンのVisit回数も2026年内のみ
- クラスタ数も2026年内にVisitしたPlace数

## 検索

検索欄は以下の両方を担う。

1. 自分がすでに登録したPlaceを検索
2. 外部施設検索サービスから新しい施設を検索

自分のPlace検索は以下を対象にする。

- Place名
- Visitタイトル
- Visitメモ（Markdown本文）

全文検索エンジンを別途導入する必要はない。
MVPでは実装コストに応じてSQLite/D1で実現可能な検索方式を使う。

自分のPlaceを選択した場合:

- 地図がそのPlaceへ移動・ズーム
- Place詳細サイドパネルを開く

未登録施設を選択した場合:

- Visit追加フォームへ進む
- Placeは裏側で自動作成される

## Place詳細

PC: 右または左のサイドパネル
スマホ: ボトムシート

地図を主役のまま維持し、別ページへ遷移しない。

表示内容:

- Place名
- 住所（補助情報）
- 訪問回数
- 初回Visit日
- 最終Visit日
- Visit履歴（新しい順）

カテゴリは基本表示しない。

## Visit

1 Place につき、1日1Visit。

同じPlaceに同じ日付で複数Visitは作らない。

Visit項目:

- 訪問日: 必須
- タイトル: 任意
- メモ: 任意、Markdown
- 外部リンク: 0件以上

ただし、以下のバリデーションを必須にする。

> メモ または 外部リンク の最低どちらか1つが必要。

ブログを書いたVisitはリンクだけでもよい。
ブログがない場合は軽いメモを残す想定。

Visitは後から何度でも編集可能。

## 外部リンク

Visit に任意個追加可能。

各リンク:

- URL
- ユーザー指定タイトル
- OGPメタデータ

登録時にOGPを取得し、DBへキャッシュする。

保持候補:
- fetched title
- description
- image URL
- site name
- fetchedAt

表示時には画像付きOGPカードを優先。

OGPが取得できない場合は普通のリンク表示にフォールバック。

外部リンクは常に別タブで開く。

必要なら管理者向けに OGP 再取得アクションを用意する。

## Place

Place は施設・スポットそのもの。

基本は外部施設検索サービス上のPOI/施設を使う。

Place情報はユーザーが手編集しない。

登録時点の施設情報をスナップショットとして保存する。

同一施設を再訪した場合、新しいPlaceは作らず、既存PlaceにVisitを追加する。

外部サービスのstable IDを同一性判定に利用する。

Place自体には以下を持たない。

- ユーザーメモ
- ユーザー外部リンク
- 評価

人間が書く情報はVisitに集約する。

## 削除

Visitは削除可能。

Visitが0件になったPlaceは、ユーザーから見ると地図から消える。

最後のVisit削除時には確認ダイアログで、

「このVisitを削除すると、この場所の訪問記録がなくなるため地図からも消えます」

と明示する。

内部的にPlaceを物理削除するか残すかは実装判断だが、公開UIにはVisit 0件のPlaceを出さない。

## URL共有

Place状態をクエリで表現する。

例:

`/?place=<placeId>`

このURLを開くと:

- 該当Placeへ地図移動
- Place詳細パネルを開く

Visitも直接リンク可能。

`/?place=<placeId>&visit=<visitId>`

このURLでは:

- Place詳細を開く
- 対象Visitが分かる状態まで展開/スクロール

## プロフィール

公開地図には作者プロフィールを控えめに表示。

項目:

- 名前
- Googleアカウントのアイコン
- 短い自己紹介
- 外部リンク複数

名前・自己紹介・外部リンクは `/admin` で編集可能。

アイコンはGoogleログインのプロフィール画像を使う。

## 公開範囲

MVPでは公開/非公開フラグを持たない。

アプリに登録した情報はすべて公開される前提。

非公開にしたい情報は登録しない運用とする。
