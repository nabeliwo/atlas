# Concepts

## Place

地図上の施設・スポット。

ユーザーが直接「Placeを作る」のではなく、Visitを追加した結果として必要なら作成される。

### 不変条件

- 外部施設検索サービス上の施設を基本単位とする
- 同一施設は同一Place
- Place単独では公開地図に現れない
- 1件以上のVisitが存在するPlaceだけが見える

## Visit

特定日にPlaceへ行ったという記録。

このアプリでユーザーが実際に作る中心データ。

### 不変条件

- 訪問日は日付のみ。時刻は持たない
- 同じ `Place × visitedDate` は1件だけ
- メモまたは外部リンクの最低1つが必要
- Visitは編集可能
- Visit履歴は新しい順

## External Link

Visitから外部の記憶へ戻る入口。

例:

- ブログ記事
- Google フォト
- YouTube
- SNS投稿
- その他Webページ

特定サービス専用カラムにはしない。

「任意URL + ユーザー指定タイトル + OGPキャッシュ」という汎用モデルにする。

## Profile

公開地図の作者情報。

このアプリはマルチユーザーサービスではないため、MVPではProfileは実質1レコード。

## Admin

唯一の編集者。

Google OAuth でログインする。

一般ユーザー向けログイン概念は存在しない。

## Cluster

地図上で近接Placeを束ねた表示。

クラスタの数字はVisit数ではなくPlace数。

## Filters

地図に表示するVisit集合を制限するもの。

MVPでは期間フィルターのみ必須。

フィルター後のVisit集合をもとに:

- 表示Place
- Visit回数
- クラスタPlace数

を再計算する。
